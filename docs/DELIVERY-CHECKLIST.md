## D. 环境与支持边界（接收方知悉）

1. 运行环境：Node ≥22.5，零 npm 运行时依赖；单机 SQLite 架构（扩展路径见 HANDOVER §5）。
2. v1.2 起所有 mock 均为显式可选回退（LLM/监测/图像/存储/发布全部具备真实实现，环境变量切换）；渠道官方 API（头条号/小红书）与付费媒体属外部凭证依赖的二期范围（评估见 HANDOVER §3 与 REAL-INTEGRATION §5）。
3. 不承诺真实平台上榜效果（方法论原则：平台偏好仅为观察假设）。真实监测/发布需配置对应 Key（见 docs/REAL-INTEGRATION.md）。
4. 生产上线前完成 `DEPLOYMENT.md §7` 检查单；v1.3 已内置密码策略/登录锁定/审计日志/协议勾选/AI 声明/备份与监控脚本（ops/）。
