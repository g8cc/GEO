# 常见问题（FAQ）

> 分四类：使用 / Skills 与 CLI / 部署运维 / 商务。运维类深度排查见 `OPERATIONS.md` Runbook；技术边界见 `AUDIT.md §3`。

## 使用类

**Q1：文章状态显示「已上传」，是不是已经发布到平台了？**
没有。状态机是：已生成 → 已上传（进入平台文章管理）→ 已创建发布任务 → 已正式发布（出现 publishedUrl）。**文章 ID 只证明平台有记录**。

**Q2：监测结果显示「弱命中」，说明什么？**
AI 的回答里出现了你的标题或账号（弱证据）。只有「精准命中」（我方正式链接被引用，exact_url_hit）才是「URL 被 AI 检索/引用」的证据；「稳定」还需要跨批次观察。

**Q3：优化前后对比为什么出不来/不准？**
对比必须**同一个问题、同一个 AI 平台、相近时间条件**。选任务时确认两个监测任务用的是同一题；不同问题各问一次的结果不能对比。

**Q4：知识库整理后有「待补充」和「口径冲突」，能继续写内容吗？**
能，但创作前输入检查会把这些标出来；相关事实缺失会导致审核第三关（GEO 可信度）降级。正确姿势：先让业务补齐/拍板口径，再创作。

**Q5：发布失败提示额度不足？**
发布确认会扣减账号额度；到「授权账号」补额度或清理无效账号后重试（发布任务页有「重新发布」）。

## Skills 与 CLI 类

**Q6：AI 说「密钥未授权项目 xxx」？**
去平台「系统设置 → Open Key」编辑当前密钥，勾上该项目——**立即生效，不用重新登录**。项目在别的账号下才需要重建密钥。

**Q7：为什么 AI 总是先给我一份"摘要"再要确认？**
写操作两步制（plan → 确认 → apply）是产品铁律，防止误解目标造成不可逆写入。摘要要完整看，数组字段是整体覆盖不是追加。

**Q8：apply 报 PLAN_EXPIRED / PLAN_USED？**
plan 30 分钟有效且只能执行一次。过期就重新 plan 重新确认；USED 说明已经执行过，去平台查结果即可。

**Q9：AI 让我安装 Python？**
不要装。全套系统（平台/CLI/Skills）零 Python 依赖，这是明确设计；遇到此提示说明技能过期，跑 `geo version --check` 升级。

**Q10：不知道该调哪个技能？**
对 AI 说「我是新学员，帮我选择合适模式并跑一个 GEO 项目」，由学员入口统一路由。

**Q：监测结果是真数据还是假数据？**
v1.1 起按平台混合：配了某平台 Key（通义/DeepSeek/豆包/混元）即走真实联网问答，未配的回落 mock；结果会区分。详见 `docs/REAL-INTEGRATION.md`。

**Q：知乎/小红书这类没有 API 的渠道怎么发布？**
按发布包手动发布，然后到「内容发布 → 手动发布回填」粘贴真实链接——文章状态与真实监测链路随之打通。

## 部署运维类

**Q11：生产部署最少的配置是什么？**
`SEED_DEMO=0 DISABLE_REGISTER=1` + HTTPS（Nginx）+ `SESSION_SECURE=1`。完整检查单：`DEPLOYMENT.md §7`。

**Q12：数据都在哪？怎么备份？**
`platform/data/geo.db`（SQLite，WAL）+ `platform/data/uploads/`。在线备份用 `sqlite3 ".backup"`，全步骤见 `DEPLOYMENT.md §5`。

**Q13：可以多台服务器吗？**
当前单机 SQLite 架构按单实例设计；横向扩展需迁移 Postgres（接口已收敛，见 `HANDOVER.md §5`）。

**Q14：升级会动数据库吗？**
结构迁移是幂等建表，自动补齐；升级前照例备份（`DEPLOYMENT.md §6`）。回滚旧代码无需回滚库。

## 商务类

**Q15：系统覆盖方法论的哪些环节？**
品牌知识库六模块 → 50/40 问 → 三类内容 + 三道审核 → 发布 → 上榜监测（0/3/7/14 天）→ 信源四状态 → 五类报告（含逆向分析与一页纸诊断）。逐条对照见 `docs/skills-and-prompts.md`。

**Q16：哪些是 mock，边界在哪？**
v1 中 AI 监测四平台与发布渠道为 mock（语义完整：发布后可复现 exact_url_hit，用于培训与流程验收）；内容生成 mock/真实双模式。真实对接点与工作量评估见 `HANDOVER.md §3`。**训练与流程交付可承诺，真实上榜效果不承诺**（方法论原文原则：平台偏好只是观察假设）。

**Q17：怎么向客户演示最有说服力？**
跑一遍七步闭环：建项目 → 50 问 → 生成品牌文章 → 三道审核 → 发布 → 监测出现 exact_url_hit → 信源资产沉淀 → 优化前后对比报告。全程约 10 分钟（mock 快速模式）。
