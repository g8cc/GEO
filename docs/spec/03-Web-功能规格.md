# GEO 平台规格说明书 03 · Web 功能规格

> 实现文件：`platform/src/web/`（ui.js 组件、routes*.js 路由）、`platform/public/style.css`。
> 认证：HttpOnly Cookie 会话（14 天）；未登录访问一律 302 → /login。注册即建账号（邮箱+密码≥6 位）。

## 1. 布局

左侧固定侧边栏：Logo、**当前项目选择器**（全局，切项目跳项目概览）、十步工作台、基础建设组（公司管理 / GEO 项目）、本项目组（选中项目后显示 14 个菜单）、系统组（系统设置·Open Key）、账号与退出。主区为卡片流。

## 3. 业务校验（Web 层）

| 场景 | 行为 |
|---|---|
| 未通过三道审核的文章创建发布任务 | 拒绝并回显原因（verdict≠通过） |
| 发布确认页 | 必须勾选确认框才能提交 |
| 监测任务创建 | 问题/平台多选；周期模式固定 3/7/14 天 |
| Open Key 创建 | 未选项目不允许提交 |
| 状态变更按钮 | 仅在合法状态下渲染（如「确认发布」仅 status=1） |

## 4. 视觉规范

- 卡片式布局 + 徽章状态色：绿=完成/已发布/精准命中/通过；黄=进行中/待复测/修改后通过；红=失败/不通过/未命中；灰=待完成；品牌紫=主操作。
- 表格统一斑马hover；空态统一「暂无数据」；Markdown 预览用等宽底色块。
