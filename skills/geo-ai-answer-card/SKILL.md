# AI 答案卡技能

## 触发词（原文，原样响应）

```text
请你调用GEO相关的技能，帮我基于xxx问题创作一个AI答案卡脚本，并生成对应的图片
```

```text
请使用 AI 答案卡技能，围绕品牌问题【粘贴问题】创作一套抖音图文。先输出脚本，等待我确认后再生成图片。内容只能使用知识库中已确认的事实和证据。
```

```text
请使用 AI 答案卡技能，围绕产品问题【问题】创作一套抖音图文。先帮助用户做选择，再说明我方产品为什么符合，不要直接写成产品广告。
```

## 操作流程

1. **确认问题与知识库**：目标问题 + 品牌/产品知识库中已确认的事实与证据。
2. **先输出脚本**（必须先停在这里等确认）：按「结论 → 判断标准 → 推荐理由 → 适用边界 → 下一步行动」结构，输出图片版文案分页（P1 封面 / P2 结论页 / P3 证据页 / P4 行动页）+ 视频口播脚本。
3. **用户确认后再生成图片**：`geo plan materials.upload --input '{"projectId":…,"name":"答案卡P1","type":1,"dataBase64":"…"}'` 逐页上传，或由平台生成封面。**不要跳过确认直接出图。**
4. 答案卡完成后进入三道审核（`geo-content-audit`）。

## 内容规则

1. 先给直接结论，再给判断标准、推荐理由、适用边界和下一步行动。
2. 所有品牌、产品、价格、案例和数据必须来自知识库；缺失信息标注待补充。
3. 内容必须围绕用户问题回答，不得写成泛泛品牌宣传。
4. 产品题：先帮助用户做选择，再说明我方产品为什么符合，**不要直接写成产品广告**。

## 发布边界

AI 答案卡图片需要学员**按平台要求手动发布到抖音图文**，不走平台自动发布；品牌/产品长文章才走 GEO 平台发布任务。
