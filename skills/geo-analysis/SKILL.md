# GEO 分析技能

## 触发词（原文，原样响应）

```text
使用 GEO 分析技能，对比竞品和自身在 AI 回答、引用来源和证据缺口上的差异。
```

```text
请调用 GEO 分析技能，对比品牌问题优化前后的结果，找出一个最主要的认知差距，并给出下一步点对点优化建议：需要补什么证据、创作什么内容、发布到哪里、用哪个原问题复测。
```

```text
请调用 GEO 分析技能，找出这个产品问题不上榜或没有被推荐的主要原因，并生成下一步优化方案。方案必须明确补什么证据、改什么内容、发到哪里、何时用同一个问题复测。
```

## 能力一：优化前后对比

```bash
geo plan reports.create --input '{"projectId":…,"type":3,"taskIdA":"<优化前任务>","taskIdB":"<优化后任务>"}'
```

**对比前后必须保持可比**（课程原文）：同一个用户问题、同一个 AI 平台、相近的监测时间和执行条件；清楚区分一次回答和多次稳定结果。不同问题或不同平台的结果不能直接当作优化前后对比。

对比指标：品牌提及、明确推荐、优先推荐、竞品占位、我方 URL 精确引用、引用来源变化。

## 能力二：逆向分析

```bash
geo plan reports.create --input '{"projectId":…,"type":4,"question":"…","platform":1,"times":10}'
```

流程（课程原文）：
1. 对同一批问题进行多平台提问，保存每一次原始回答；
2. 对同一个问题重复提问约 10 次，记录每次回答的变化；
3. 提取核心实体、场景、地域、功能、价格、效果、对比和行动关键词；
4. 统计关键词出现频率，区分稳定需求、长尾需求和竞品优势词；
5. 对比竞品和自身的回答内容、推荐理由、引用文章和引用来源；
6. 形成「问题 → AI 差异 → 引用来源差异 → 缺失证据 → 内容与信源动作 → 复测结果」。

**关键词频次是逆向分析工具，不是 AI 平台公开的权重。** 记录模板见 [references/逆向分析记录模板.md](references/逆向分析记录模板.md)。

## 能力三：下一轮点对点优化

输出必须明确四件事（课程原文）：**补什么证据、创作什么内容、发布到哪里、用哪个原问题复测。** 每轮只做一个主要优化动作，保存优化前后对比。

## 能力四：流量承接检查（文档二 6.1 原文）

```text
请检查【官网/产品页/咨询页/新媒体主页】是否能承接来自 AI 的推荐流量：
1. 开头是否立即说明服务对象和能解决的问题。
2. AI 给出的推荐理由是否能在页面找到对应证据。
3. 用户能否判断自己是否适合，是否写清适用条件和不适用情况。
4. 价格、流程、风险、案例和服务边界是否清楚。
5. 下一步行动是否明确，联系方式、预约入口和响应承诺是否可用。
请输出：缺口、影响、优先级、修改建议和需要补充的证据。
```

客户验证路径记录见 [references/承接与验证模板.md](references/承接与验证模板.md)。

## 行为约束

- 报告必须区分事实、推断和待验证信息，不编造企业数据。
- 平台引用偏好只能作为观察假设，不是固定算法或发布保证。
- 没有监测结果时先建监测任务，不要凭想象分析。
