# 未覆盖问题的循环优化（文档二 5.9 原文）

```text
当我向你提问"【问题/关键词】"时，请说明你在联网状态下进行语义解析、检索、匹配、验证和答案排序的完整过程。

再检查以下【品牌/产品资料或文章】是否足以匹配这个问题：
1. 缺少哪些事实、证据、案例、参数、评价或边界。
2. 相关性不足在哪里，应该补充什么答案型内容。
3. 可信度不足在哪里，应该补充什么信源和交叉验证。
4. 给出点对点的内容、信源和复测动作。
所有不确定判断明确标注，不得臆测。
```

# GEO 逆向分析（文档一六(五) 原文流程）

1. 对同一批问题进行多平台提问，保存每一次原始回答。
2. 对同一个问题重复提问约 10 次，记录每次回答的变化。
3. 提取核心实体、场景、地域、功能、价格、效果、对比和行动关键词。
4. 统计关键词出现频率，区分稳定需求、长尾需求和竞品优势词。
5. 对比竞品和自身的回答内容、推荐理由、引用文章和引用来源。
6. 形成「问题 → AI 差异 → 引用来源差异 → 缺失证据 → 内容与信源动作 → 复测结果」。
