# 品牌诊断技能

## 触发词（原文，原样响应）

```text
请调用品牌诊断技能，读取我最近的豆包监测任务，让我选择后生成品牌诊断报告。
```

```text
请调用产品推荐诊断技能，读取我最近的豆包监测任务，让我选择后生成产品推荐诊断报告。
```

## 操作流程

1. **列出可选任务**：`geo call monitorTasks.list --input '{"projectId":…}'`——把最近的任务（时间 + 问题数 + 平台）列给用户选择，**不需要用户自己查找任务 ID**。
2. **读取结果**：`geo call monitorResults.list --input '{"taskId":…}'`。
3. **生成报告**：`geo plan reports.create --input '{"projectId":…,"type":1}'`（品牌诊断）或 `{"type":2}`（产品推荐诊断）→ apply → 把报告全文展示给用户。
4. **指出最重要的病根**（只选一个）：AI 不认识品牌 / 认识但不引用我方链接 / 描述不准确 / 竞品占位。

## 品牌诊断要回答的问题

- AI 是否认识品牌？如何描述？描述是否准确（品牌描述准确性来自知识库完整度对照）？
- 为什么推荐或不推荐我方？推荐理由与知识库事实是否一致？
- 竞品是谁？为什么竞品被引用/推荐（引用了什么文章、什么平台）？
- 最重要的病根是什么？

## 产品推荐诊断的差异

重点看：AI 是否推荐产品、推荐了谁、依据是什么；选择标准类内容（怎么选/适合谁）是否进入候选；推荐是否稳定（需多次观察，不能把不同问题各问一次当成稳定结果）。

## 归因诊断（文档二 1.4 原文，用户直接问 AI 平台时使用）

```text
我是【品牌名】的运营负责人。我刚才询问了"【具体测试问题】"，在你的推荐答案中并未出现我们的品牌。
请从你的检索与生成机制出发，进行一次客观归因分析：
1. 在回答该类问题时，你优先参考了哪些网络渠道和信源？请按可信度排序说明。
2. 一个同行业品牌要进入你的推荐候选名单，通常需要具备哪些公开信息与第三方证明？
3. 根据当前全网可检索信息，我们主要缺少哪些维度的内容（如权威测评、参数结构化数据、用户真实评价、资质备案等）？
4. 请给出一个符合你抓取偏好的标准内容结构示例，以便我们完善公开信息。
（注：请客观陈述，不确定的部分明确标明"不确定"，切勿臆测。）
```

## 卡点

没有监测结果 → 检查任务、平台、问题和完成状态，**不要凭想象诊断**。先引导用户创建监测任务（`geo-indexing`）。
