# GEO 配置技能

## 一、初始化接口密钥

1. 让学员登录 GEO 平台网页，进入 **系统设置 → Open Key**，创建个人接口密钥，并勾选要授权的 GEO 项目（改授权立即生效，不需要重建密钥）。
2. 由你（AI）执行 `geo auth login --server <平台地址>`：
   - 命令会阻塞最长 5 分钟，往 stderr 打一个 `http://127.0.0.1:…` 的本机地址；
   - 把这个地址转达给学员，让他在浏览器里粘贴密钥；
   - 一直等它自己退出，不要中断、不要重开一条命令。
3. **密钥只写入本地配置（~/.geo/config.json）**：不要让学员把密钥发到聊天窗口、不要替学员输入、不要写进任何项目文件或群聊。
4. 验证：`geo auth status`。

## 二、确认默认公司和产品

```bash
geo call projects.list
```

- 把返回的项目列表（名称）展示给学员，让学员选择；**projectId 不确定时不要猜，不要从旧公司或产品编号推导**。
- 公司与产品决定后续知识库、文章、发布和监测数据归属于哪个项目。
- 之后所有调用都显式带上学员选定的 `projectId`，每次都要带，不要假设有"当前项目"。

## 三、项目不在列表里时

1. 大多数情况：项目在当前账号下——让学员去网页「密钥管理」编辑这把密钥授权的项目，勾上即可，**立即生效，不需要重新登录**；改完再 `geo call projects.list` 确认。
2. 少数情况：项目在另一个账号下——需要用那个账号新建密钥重新 `geo auth login`（新密钥会顶替本机原有授权）。
3. 判断不了就直接问学员：「这个 GEO 项目是在你当前登录的账号下吗？」
