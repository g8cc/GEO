# 内容审核技能

## 三道审核关（课程原文）

1. **知识库一致性**：品牌名、产品名、功能、价格、案例、数据、时间和服务边界必须与知识库一致。
2. **媒体投稿标准**：标题、篇幅、结构、图片、链接、广告披露和平台规范符合目标媒体要求。
3. **GEO 要求**：内容是否精准回答用户问题，是否有足够的可信来源、证据、交叉验证和可访问页面。

**三道审核中任何一道不通过，都不应直接进入重点投放。** 发现事实缺口时，先回知识库补证；发现相关性不足时，先重写问题和答案结构；发现媒体标准不合格时，先按目标平台重新编辑。

## 触发词（原文）

```text
请你调用GEO相关的技能，帮我审核这篇文章内容
```

```text
帮我审核这篇内容，检查知识库一致性、媒体投稿标准和 GEO 相关性与可信度。
```

## 操作

### 平台审核（推荐，结果入库可回查）

```bash
geo plan articles.audit --input '{"articleId":…}'
# 摘要：将对文章执行三道关审核并生成审核记录 → 学员同意 → geo apply
```

返回逐关结论（通过/修改后通过/不通过）+ 每关问题定位。

### 创作前输入检查（3.1 原文）

```bash
geo call preflight.check --input '{"projectId":…,"questionId":…}'
```

```text
请根据以下资料，基于GEO的技能，检查本次 GEO 内容创作是否具备完整输入：
1. 品牌知识库：是否有定位、产品事实、适用边界、案例和证据。
2. 目标问题：用户对象、场景、条件、决策任务是否明确。
3. 证据任务：这条内容需要证明哪些事实，现有资料是否足够。
4. 发布要求：目标平台、内容形态、字数、图片/视频和合规限制。
请将结果分为"已具备 / 待补充 / 不可使用"，不得自行补写事实。
```

### 一键审核提示词（3.5 原文，平台无记录时的人工审核模板）

```text
请对以下内容基于GEO的技能，执行三道关审核，并逐项给出"通过 / 修改后通过 / 不通过"及修改建议：
第一关：内容是否与品牌/产品知识库一致，是否出现事实冲突、过时信息或未经确认的数字。
第二关：内容是否符合目标媒体投稿标准，包括标题、结构、字数、图片/视频、广告法和平台规范。
第三关：内容是否符合 GEO 要求，即是否精准回答目标问题，是否有足够可信度、证据、来源和交叉验证。

输出：问题定位 → 证据依据 → 修改方案 → 修改后的完整段落。
```
