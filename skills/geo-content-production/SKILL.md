# 内容创作技能

## 触发词（原文）

```text
使用内容创作技能，基于这个问题和知识库生成 AI 答案卡、品牌优化文章和产品推荐文章。
```

```text
请你调用GEO相关的技能，帮我基于xxx问题创作一篇品牌介绍的文章和封面
```

```text
请你调用GEO相关的技能，帮我基于xxx问题创作一篇产品推荐的文章和封面
```

## 创作前准备（课程原文）

1. 确认用户原始问题、对象、场景、限制条件和决策任务。
2. 确认使用品牌知识库还是产品知识库，必要时同时调用两类知识库。
3. 列出需要证明的结论，以及每个结论对应的案例、数据、资质、产品事实或第三方链接。
4. 确定内容载体：文章、图片或视频；再确定发布平台和承接入口。

先跑创作前输入检查：`geo call preflight.check --input '{"projectId":…,"questionId":…}'`（结果分「已具备 / 待补充 / 不可使用」，不得自行补写事实）。

## 三类内容资产

| 内容资产 | 适合解决的问题 | 操作重点 |
|---|---|---|
| AI 答案卡 | 直接回答一个明确问题 | 结论先行，保留事实、证据和适用边界 |
| 品牌优化文章 | 品牌是谁、是否专业、为什么值得信任 | 写清身份、能力、案例、证据和服务边界 |
| 产品推荐文章 | 产品适合谁、怎么选、为什么推荐 | 写清场景、条件、差异、限制和行动入口 |
| 图片或视频内容 | 把结论、步骤和证据变成易理解的多模态内容 | 视觉帮助理解，关键事实仍要保留在可读取文字中 |

## 创作命令

```bash
# AI 答案卡（三形态：文章版正文 / 图片版文案 / 视频口播版脚本）
geo plan articles.create --input '{"questionId":…,"type":1}'
# 品牌优化文章 + 封面
geo plan articles.create --input '{"questionId":…,"type":2}'
# 产品推荐文章 + 封面
geo plan articles.create --input '{"questionId":…,"type":3}'
```

每条 plan 会展示「将基于哪个问题创作什么」；学员同意后 `geo apply <planId>`；文章与封面随即进入平台（状态=已上传）。

## 创作铁律（提示词原文，内置在平台生成逻辑中）

- 品牌文章：「文章必须先回答用户问题，再用真实事实、案例和边界说明支撑结论。」
- 产品文章：「文章必须包含选择标准、适用条件、证据、边界和行动入口。」「先帮助用户做选择，再说明我方产品为什么符合，不要直接写成产品广告。」
- 答案卡：「先输出脚本，等待我确认后再生成图片。内容只能使用知识库中已确认的事实和证据。」
- 第三方口吻与媒体适配要求见 [references/第三方口吻与媒体适配.md](references/第三方口吻与媒体适配.md)。

## 状态机

已生成 → 已上传（进入平台文章管理）→ 已创建发布任务 → 已正式发布。
**「已生成」不代表已上传；「已上传」不代表已发布。** 创作完成后必须进入 `geo-content-audit` 三道审核。
