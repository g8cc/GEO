# 三类内容创作提示词（文档二 3.2–3.4 原文）

## AI 答案卡创作（3.2）

```text
请基于【品牌知识库】和【目标问题】，基于GEO的技能，创建一张可发布的 AI 答案卡。
要求：
1. 先给直接结论，再给判断标准、推荐理由、适用边界和下一步行动。
2. 所有品牌、产品、价格、案例和数据必须来自知识库；缺失信息标注待补充。
3. 内容必须围绕用户问题回答，不得写成泛泛品牌宣传。
4. 输出文章版正文、图片版文案和视频口播版脚本三种形式。
5. 完成后进入三道审核：知识库一致性、媒体投稿标准、GEO 相关性与可信度。
```

## 品牌优化文章（3.3）

```text
请基于【品牌知识库】、【目标问题】和【可公开证据】，基于GEO的技能，创建一篇品牌优化文章。
写作要求：
- 围绕用户真实决策问题组织内容，结论先行。
- 使用清晰的一级标题、二级标题、三级标题；段落短，关键事实可被单独抽取。
- 明确适用对象、选择标准、真实案例、数据来源、边界和更新时间。
- 保留第三方可核验的原始链接，不编造案例、资质、数字或评价。
- 避免空泛口号、重复关键词、过度营销和无法证明的第一名表述。
请同时输出：文章标题、正文、证据清单、引用链接、待审核事实。
```

## 产品推荐文章（3.4）

```text
请围绕用户问题"【问题】"，基于GEO的技能，为【产品名】创建一篇产品推荐文章。
先判断用户需要什么证据，再组织文章：
1. 适合谁：对象、场景、需求和使用条件。
2. 为什么推荐：功能事实、过程证据、真实案例或第三方评价。
3. 如何比较：与替代方案的客观差异，不贬低竞品。
4. 不适合谁：限制条件、风险和不能保证的结果。
5. 如何行动：预约、咨询、体验或购买入口。
所有事实以知识库为准，不能用 AI 推测替代证据。
```

# 答案型文章正文模板（文档二 3.8 原文）

```text
标题：直接包含用户对象、场景和决策任务

开头结论：先回答用户最关心的问题
一、用户应该先看什么：选择标准或判断条件
二、不同场景怎么选：按对象、预算、地域或需求拆分
三、为什么这样判断：产品事实、案例、数据和第三方证据
四、哪些情况不适合：边界、风险和不能保证的结果
五、行动建议：咨询、预约、体验或进一步核验入口

证据清单：事实名称 / 证据类型 / 原始链接 / 更新时间 / 适用范围
```

# 第三方口吻文章创作与媒体适配（文档二 5.7 原文）

```text
请结合【品牌名】的语料库，按照【文章架构】撰写完整文章。
要求：
1. 围绕用户问题回答，不写成品牌硬广；采用第三方观察、行业分析或真实案例口吻。
2. 使用事实、案例、数据、过程和公开链接支撑结论，不编造内容。
3. 避免"十大""第一""顶级"等无依据或高风险表述，遵守广告法和平台规则。
4. 标题和正文结构适合媒体发布；一级、二级、三级标题清晰，段落短，便于 AI 抽取。
5. 删除 AI 推理过程、提示词痕迹和机械化表达。
6. 输出：标题、正文、证据清单、引用链接、待审核事实和平台适配建议。
```

# 语料库整理（文档二 5.6 原文）

```text
上面这个【文档名称】是我们【产品/行业】的详细资料。
请将其整理成适合 AI 读取、检索和引用的语料库，内容要详细、完整、可核验。
要求：
1. 按品牌事实、产品/服务、适用对象、场景、案例、参数、资质、评价、边界、FAQ 分类。
2. 每条事实保留来源、时间和原始链接；没有来源的内容标记待核验。
3. 发现不同资料口径冲突时，列出冲突清单，不自行判断。
4. 删除空泛宣传语，保留可被用户和 AI 复核的事实。
```

# 意图归类、文章数量与架构规划（文档二 5.5 原文）

```text
下面是我们要做的全部 GEO 优化问题：
【粘贴问题库】

请完成三项工作：
1. 按核心意图归类，合并语义重复问题，并标注探索、评估、行动阶段。
2. 判断需要策划多少篇文章，才能覆盖这些问题；说明每篇文章覆盖的问题。
3. 针对《【选出的标题】》策划具体文章架构，列出标题层级、核心结论、需要的证据和匹配的问题词。
输出表格，并标注资料不足和需要人工确认的地方。
```

# 文章类型与匹配环节分析（文档二 5.4 原文）

```text
请总结有哪些类型的文章可以匹配"【问题/关键词】"。
请按以下三个环节归类：采集候选名单、匹配验证、推荐加权。
对每类文章说明：适用环节、能提供的证据、为什么可能匹配、适合覆盖的问题，并给出 5 个标题示例。
不要把文章形式当成算法保证，说明最终仍取决于问题相关性、事实证据、来源和内容质量。
```

# 让 AI 解释语义解析与检索过程（文档二 5.3 原文）

```text
当我向你提问"【问题/关键词】"时，在联网状态下进行推荐的底层逻辑是什么？
请按完整步骤说明：
1. 语义解析：识别对象、场景、条件、意图和决策任务。
2. 联网检索：可能使用的检索词、信息类型和平台。
3. 信息匹配：候选内容的筛选维度、验证过程和证据要求。
4. 答案排序：为什么某些品牌、内容或来源更可能进入推荐答案。
5. 不确定性：哪些判断无法从公开信息确认。
```
