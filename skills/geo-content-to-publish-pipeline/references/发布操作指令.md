# 发布操作指令（文档二 3.6 原文）

```text
请基于GEO的技能，将审核通过的内容整理为发布包：
1. 平台：目标发布平台。
2. 标题：平台适配标题。
3. 正文：最终发布正文。
4. 图片/视频：文件名、顺序和说明。
5. 账号：发布账号与账号类型。
6. 链接：知识库证据链接和 CTA 链接。
7. 回填字段：发布状态、正式 URL、发布时间、平台、账号、版本号。

手动发布：输出可直接复制到平台后台的完整发布包。
自动发布：调用 GEO 发布助手创建发布任务；创建后仍需人工确认预览、账号、素材、链接和最终发布状态。
```

## 平台发布包结构（publishTasks.create 自动生成）

`geo plan publishTasks.create` 的摘要就是上述 7 字段发布包：

1. 平台（platform / platformLabel）
2. 标题（title）
3. 正文（content）
4. 图片/视频（media：文件、顺序、说明）
5. 账号（account：名称、账号类型）
6. 链接（links：知识库证据链接 + CTA 链接）
7. 回填字段（backfill：发布状态、正式 URL、发布时间、平台、账号、版本号）

## 手动发布场景

平台不能代发的内容（如抖音答案卡图片、部分需要人工操作的后台），输出完整发布包文本，由学员复制到平台后台手动发布；发布后把正式 URL 通过 `geo plan sources.upsert` 登记到信源资产（页面状态=已正式发布）。
