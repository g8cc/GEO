# 收录检测（文档二 5.8 原文）

```text
全网抓取标题为《【想要检测的标题】》的稿件被 AI 收录的媒体发布情况，仅返回：媒体名称 + 对应官方发布网址。
无需输出其他多余信息，按清晰格式呈现；无法确认是官方发布页面的结果请标注"待核验"。
```

平台对应：`geo call monitorResults.list` 查看每条结果的 citations（媒体名称 + URL + 是否我方 own）；收录站点聚合视图在平台「上榜监测 → 收录站点」。

# 判断口诀（课程原文）

```text
articleId ≠ 已发布
publishedUrl ≠ AI 已看见
weak_title_account_hit ≠ 精确收录
exact_url_hit 才能作为 URL 被 AI 引用/检索到的证据
stable 需要跨批次/跨平台持续出现
```
