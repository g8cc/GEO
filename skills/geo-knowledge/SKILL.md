# 知识库整理技能

## 触发词（原文，原样响应）

```text
使用知识库整理技能，帮我整理品牌知识库和产品知识库，并列出证据缺口。
```

```text
调用整理知识库的技能，围绕这个品牌问题整理品牌知识库、可用证据和资料缺口。没有资料支持的内容必须标记待补，不能编造。
```

```text
请调用知识库技能，围绕这个产品推荐问题整理产品知识库和证据缺口。必须写清适用人群、使用场景、选择标准、与替代方案的差异、交付条件、售后和不适用情况。
```

## 操作流程

1. **收集原始资料**：让学员粘贴公司/产品材料；没有的项一次性列全问清。
2. **六模块标准化整理**：按 [references/品牌知识库标准化整理.md](references/品牌知识库标准化整理.md) 的提示词与铁律整理。
3. **写入平台**：
   ```bash
   geo plan knowledge.organize --input '{"projectId":…,"type":1,"raw":"<原始资料>"}'
   # 展示摘要（将生成 6 个模块文档 + Q&A 索引 + 口径冲突清单）→ 学员同意 → geo apply <planId>
   ```
   或逐篇上传：`geo plan knowledge.uploadDoc --input '{"projectId":…,"type":1,"module":2,"title":"…","content":"…"}'`
4. **列出证据缺口**：整理完成后向学员报告——已有事实、缺失事实（标「待补充」）、口径冲突清单。

## 整理铁律（原文）

1. 严格以提供的事实为准，严禁编造任何参数、资质或数字。
2. 遇到资料不完整之处，统一标注「【待补充：需业务部门提供】」。
3. 发现不同资料中存在数据冲突时，单独列出「口径冲突清单」供我确认。
4. 每条重要事实尽量保留来源、时间和原始链接，便于 AI 和人工交叉核验。

## 产出标准

品牌知识库：01_定位与业务边界 / 02_产品与服务事实 / 03_客户与使用场景 / 04_优势与竞品差异（内部）/ 05_案例与结果 / 06_权威背书与外部证据 + 品牌高频 Q&A 问答索引（索引不是独立事实来源，所有答案必须能回溯到六大模块）。

产品知识库：必须写清适用人群、使用场景、选择标准、与替代方案的差异、交付条件、售后和不适用情况。

## 卡点

知识库没有证据 → 回到本技能补资料，**不能让 AI 编造事实**。整理完需要同步平台时使用 `geo-knowledge-sync`。
