# 商务沟通、信息调研与成交答疑模板（课程原文）

> 用途：商务沟通场景下的一页纸诊断、沟通提纲、现场纪要、方案要点和锁定话术。所有【】占位需替换为真实资料；诊断结论必须来自真实监测数据，不得臆测。

## 1. AI 现状一页纸诊断

```text
【调研对象】XXX品牌 · AI 现状一页纸诊断（日期：YYYY-MM-DD）
1. 抽样实测：平台名称 + X 个核心问题抽样
2. 现状诊断：
   - 探索层表现：是否进推荐名单、当前排位
   - 评估层表现：AI 描述是否准确、有无过时差评
   - 行动层表现：电话、地址、官网通路是否畅通
3. 竞品差距：核心竞品名称 + 竞品在 AI 中的优势表现
4. 最扎眼的问题：当前 AI 对品牌最核心的一处错误描述
5. 预设 3 个开场首问：认知水位问 / 获客成本问 / 决策流程问
6. 下一步推进建议：一句话明确首期重点（如：先止血修错，后铺设增量）
```

平台能力：`geo call reports.create --input '{"projectId":…,"type":5,"platform":1}'` 生成抽样实测，再按上述结构整理成页。

## 2. 15—30 分钟商务沟通提纲

```text
0–5 分钟 【破冰开场】
报告已发：看完简报，哪一条发现您最想先探讨？
报告未发：实测同类推荐中暂未检索到咱们，今天先向您请教真实获客情况。

5–15 分钟 【必问三件套】
① 您平时关注过咱们在 AI 中的呈现吗？
② 目前主要获客渠道及单客获取成本是多少？
③ 这类项目内部的决策流程与大致预算区间如何？

15–25 分钟 【摊开诊断与回问】
先指竞品优势，再指自身错漏；3 分钟讲清优化逻辑后回问：这几个环节中，您觉得最迫切要解决的是哪块？

25–30 分钟 【方案匹配、异议与锁定】
按阶段匹配方案；用"认事实 → 问原因 → 给动作"回应异议；散场锁定人、时间、交付物。
```

## 5. 三锁定标准话术

```text
锁定决策人：下次沟通时，能否邀请负责业务审批的负责人一同线上沟通？针对他关心的投入产出模型，我单独做一次测算演示。

锁定具体时间：我们定在下周四下午 15:00 进行方案对齐，大约 30 分钟，您看是否方便？

锁定交付材料：本周三前我会把定制方案发给您；麻烦您周四前把主推业务的基础参数资料同步一份。

客户暂无明确时间时的自锁：好的，那我把跟进日程定在下周五上午，届时致电与您同步最新的竞品数据进展。
```
